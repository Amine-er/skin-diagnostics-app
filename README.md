# SkinDeep Insights

## Core Features:

- Photo Upload: Photo upload and storage: Allow users and pros to upload skin photos. Store the photo URL.
- AI Diagnostics: Diagnostic scoring: Provide a score (1-100) for five key skin properties based on the photo using an AI tool.
- History Logging: Diagnostic history: Maintain a history of all skin diagnostics for each user or pro-created profile.
- Recommendations: Product recommendations: Recommend a single product (identified by barcode) based on diagnostic results.
- Pro Profiles: Profile management: Professional accounts can manage profiles (first name, last name, phone number) of non-registered users.
- Score Visualization: Display score summary: Visualize scores for the five properties
